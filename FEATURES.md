## Game Statistics

### Content
- 4 Tower Types
- 10 Waves
- Dynamic Enemy Spawning
- ~30 Enemies per late-game wave
- Progressive Difficulty Scaling

### Balance Numbers
- Starting Money: $500
- Starting Base Health: 100
- Basic Tower: $100, 100 range, 10 damage, 1.0s fire rate
- Rapid Tower: $150, 80 range, 5 damage, 0.3s fire rate
- Sniper Tower: $250, 200 range, 50 damage, 3.0s fire rate
- Splash Tower: $200, 90 range, 15 damage, 1.5s fire rate

## What Makes This Game Fun

### Strategic Depth
1. **Tower Placement** - Position matters! Early path placement maximizes damage
2. **Resource Management** - When to save vs spend creates tension
3. **Tower Synergy** - Combining different tower types is more effective
4. **Adaptive Strategy** - Each wave requires adjustment and planning

### Progression
1. **Difficulty Curve** - Starts easy, becomes challenging
2. **Economic Growth** - Money accumulation enables better defenses
3. **Wave Completion** - Each wave feels like an achievement
4. **Long-term Planning** - Must think ahead for later waves

### Player Agency
1. **Choice** - Multiple valid strategies
2. **Risk/Reward** - Expensive towers are powerful but limit options
3. **Reaction** - Can adapt strategy during waves
4. **Mastery** - Skill improves with practice

### Satisfying Mechanics
1. **Visual Feedback** - See towers shoot and enemies fall
2. **Numbers Going Up** - Money increases, waves progress
3. **Tower Variety** - Different towers feel different
4. **Win Condition** - Clear goal to achieve
